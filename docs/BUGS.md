# Bugs fixed during the port

| # | Legacy location | Bug | Fix | Regression test |
|---|---|---|---|---|
| 1 | `App/v8xml/XmlSerializer.cpp` (TextXmlParser::readText, TextXmlWriter) | Leading whitespace in single-line strings was lost on save and reload, because the reader skips whitespace before text and the writer only uses CDATA for multi-line text | The writer encodes leading whitespace as numeric entities | `rbx-format` `xml::tests::keeps_leading_whitespace` |
| 2 | `App/v8xml/XmlSerializer.cpp` (TextXmlParser) | A missing child element (for example a Vector3 without `<Z>`) dereferenced a null pointer | Missing components read as 0 | covered by `rbx-format` place round-trip test |
| 3 | `content/fonts/characterR15.rbxm` | File damaged by LF to CRLF conversion before it was committed | Rebuilt by trying each ambiguous CR LF pair until every chunk decompresses and the chunk chain is complete | `rbx-format` `tests/places.rs` |
| 4 | `App/v8datamodel/MegaCluster.cpp` (autoWedgeCellScript) | The inverse corner wedge check read `sides[(n - 1) % 4]`, which is `sides[-1]` for `n = 0`, an out-of-bounds stack read | Uses `sides[(n + 3) % 4]`, the neighbor the code meant | `rbx-terrain` autowedge code path, covered by the terrain place runs |
| 5 | `rbx-format` XML reader (port) | Strings holding raw bytes written as `&#255;`-style entities became lossy UTF-8, which broke legacy `ClusterGridV2` terrain | Non-UTF-8 strings load as raw bytes and string properties keep them | `rbx-dom` `tests/terrain.rs` |
| 6 | `rbx-physics` assembly rebuild (port) | Offsets were built from a root CFrame that was slightly off orthonormal, so every rebuild squared the error until the assembly exploded | Root frame and offsets are orthonormalized | `rbx-physics` `tests/places.rs` (600 steps, all finite) |
| 7 | `rbx-physics` contact pairs (port) | A stale pair cleared its manifolds but kept parry's manifold workspace, whose sub-detectors then indexed the empty list and panicked in about 25 places | Clearing a pair also drops its workspace |
| 8 | `rbx-physics` workspace settings (port) | `PhysicalPropertiesMode` was mapped by position instead of by enum value (`Legacy` is 0, `Default` is 1), so Default places simulated with legacy densities and friction | Maps value 0 to Legacy and gives Workspace the legacy default of `Default` |
| 9 | `rbx-script` resume check (port) | Threads of disabled scripts were stopped at their first yield even when TestService had started them on purpose, so tests with a disabled TestService script never finished | TestService-started scripts skip the Disabled check, as in `TestService::startScript` |
| 10 | `rbx-physics` solver (port) | Bodies the solver doesn't simulate and has no cache for (the terrain ground body, anchored parts) got an identity inverse inertia because glam's `Mat3::default()` is the identity, so contacts far from the origin looked rotationally weightless and the velocity stage applied almost no impulse; resting assemblies kept gaining gravity velocity, slid too far and fell through terrain | Their mass and inertia are zero, as in `PGSSolver::initAnchoredObjects` |
| 11 | `rbx-script` LoadCharacter (port) | Characters were built from `character3.rbxm` without the `Humanoid::buildJoints` step, so they had no RootJoint, Neck, shoulders or hips; a character that fell even a few studs hit the humanoid's no-neck death check, broke apart and never walked | `load_character` builds the six R6 Motor6Ds and the Status object before parenting the model, as `Player::loadCharacter` does |
| 12 | `rbx-script` script rescans (port) | Rescanning scripts when the local player's Character changed stopped TestService scripts, because the normal run rules don't cover TestService; client tests were cut off as soon as their character spawned | Scripts that TestService started are skipped by the rescan |
